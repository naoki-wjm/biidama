#雑記

脚注の番号1は本文に出てきた順に振る。名前は数字でなくてもよく、定義の順番2とも関係ない。
同じ注を二度呼ぶ1と、戻る矢印が二つになる。

これは大事な所(ところ)で、記事A も印の中に入る。a == b のような空白つきの等号と、下の飾り線は印にならない。

========

表 印
[^hub] と ==x== コードの中はそのまま

見出しの中2の番号は id に入らない

中身の無い番号[^none]は文字のまま残る。文中の 生 HTML の属性の中も触らない。

    行を続けて書ける

    四つの空白で下げると、同じ注の二段落目になる ↩↩

  2. 二つ目に呼ばれた注。注(ちゅう)の中でもルビ・強調・記事B・https://example.com/ が使える ↩↩
